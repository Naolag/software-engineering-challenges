# Software Engineering Challenges

This repository contains algorithmic problems, debugging tasks, system design exercises, and API/database challenges.  
Each challenge includes:
- **Problem.md** → description of the problem
- **Solution.py / Solution.js** → primary solution
- **AlternativeSolution.py / AlternativeSolution.js** → different approach
- **Evaluation.md** → analysis of correctness, complexity, readability, maintainability, and edge cases
